| Environmental Variable | Type    | Default           | Description                                                              |
| ---------------------- | ------- | ----------------- | ------------------------------------------------------------------------ |
| **`LFM_ID`**           | string  |                   | A globally unique ID                                                     |
| `LFM_NAME`             | string  | Value of `LFM_ID` | A vanity name                                                            |
| `LFM_ENABLE`           | boolean |                   |                                                                          |
| `LFM_SLUG`             | union   |                   | The URL ending that should be used to identify scrobbles for this source |
