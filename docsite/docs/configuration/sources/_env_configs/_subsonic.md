| Environmental Variable  | Type    | Default                | Description                                       |
| ----------------------- | ------- | ---------------------- | ------------------------------------------------- |
| **`SUBSONIC_ID`**       | string  |                        | A globally unique ID                              |
| `SUBSONIC_NAME`         | string  | Value of `SUBSONIC_ID` | A vanity name                                     |
| `SUBSONIC_ENABLE`       | boolean |                        |                                                   |
| **`SUBSONIC_USER`**     | string  |                        | Username to login to the server with              |
| **`SUBSONIC_PASSWORD`** | string  |                        | Password for the user to login to the server with |
| **`SUBSONIC_URL`**      | string  |                        | URL of the subsonic media server to query         |
