| Environmental Variable | Type    | Default                       | Description                                               |
| ---------------------- | ------- | ----------------------------- | --------------------------------------------------------- |
| **`SOURCE_LZ_ID`**     | string  |                               | A globally unique ID                                      |
| `SOURCE_LZ_NAME`       | string  | Value of `SOURCE_LZ_ID`       | A vanity name                                             |
| `SOURCE_LZ_ENABLE`     | boolean |                               |                                                           |
| `SOURCE_LZ_URL`        | string  | https://api.listenbrainz.org/ | URL for the ListenBrainz server, if not using the default |
| **`SOURCE_LZ_TOKEN`**  | string  |                               | User token for the user to scrobble for                   |
| **`SOURCE_LZ_USER`**   | string  |                               | Username of the user to scrobble for                      |
