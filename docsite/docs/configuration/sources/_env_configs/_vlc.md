| Environmental Variable | Type    | Default           | Description                              |
| ---------------------- | ------- | ----------------- | ---------------------------------------- |
| **`VLC_ID`**           | string  |                   | A globally unique ID                     |
| `VLC_NAME`             | string  | Value of `VLC_ID` | A vanity name                            |
| `VLC_ENABLE`           | boolean |                   |                                          |
| `VLC_URL`              | string  | localhost:8080    | URL:PORT of the VLC server to connect to |
| **`VLC_PASSWORD`**     | string  |                   | Password for the server                  |
