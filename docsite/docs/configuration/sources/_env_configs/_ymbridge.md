| Environmental Variable | Type    | Default                | Description                                                                 |
| ---------------------- | ------- | ---------------------- | --------------------------------------------------------------------------- |
| **`YMBRIDGE_ID`**      | string  |                        | A globally unique ID                                                        |
| `YMBRIDGE_NAME`        | string  | Value of `YMBRIDGE_ID` | A vanity name                                                               |
| `YMBRIDGE_ENABLE`      | boolean |                        |                                                                             |
| **`YMBRIDGE_URL`**     | string  |                        | URL of the local Python bridge, for example http://yandex-music-bridge:9980 |
| `YMBRIDGE_API_KEY`     | string  |                        | Optional API key sent as X-API-Key to the bridge                            |
