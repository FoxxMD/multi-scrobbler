| Environmental Variable | Type    | Default             | Description                                                  |
| ---------------------- | ------- | ------------------- | ------------------------------------------------------------ |
| **`MCAST_ID`**         | string  |                     | A globally unique ID                                         |
| `MCAST_NAME`           | string  | Value of `MCAST_ID` | A vanity name                                                |
| `MCAST_ENABLE`         | boolean |                     |                                                              |
| **`MCAST_URL`**        | string  |                     | The host or URL of the YamahaExtendedControl endpoint to use |
