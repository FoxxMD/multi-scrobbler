| Environmental Variable      | Type    | Default                        | Description                                                          |
| --------------------------- | ------- | ------------------------------ | -------------------------------------------------------------------- |
| **`SPOTIFY_ID`**            | string  |                                | A globally unique ID                                                 |
| `SPOTIFY_NAME`              | string  | Value of `SPOTIFY_ID`          | A vanity name                                                        |
| `SPOTIFY_ENABLE`            | boolean |                                |                                                                      |
| **`SPOTIFY_CLIENT_ID`**     | string  |                                | spotify client id                                                    |
| **`SPOTIFY_CLIENT_SECRET`** | string  |                                | spotify client secret                                                |
| `SPOTIFY_REDIRECT_URI`      | string  | http://localhost:9078/callback | spotify redirect URI -- required only if not the default shown here. |
