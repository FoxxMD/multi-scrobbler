| Environmental Variable    | Type    | Default                | Description                                                   |
| ------------------------- | ------- | ---------------------- | ------------------------------------------------------------- |
| _**`MIXCLOUD_ID`**_       | string  |                        | A globally unique ID EX `myComponentId`                       |
| `MIXCLOUD_NAME`           | string  | Value of `MIXCLOUD_ID` | A vanity name EX `My Cool Component`                          |
| `MIXCLOUD_ENABLE`         | boolean | true                   | Should this component be used?                                |
| _**`MIXCLOUD_USERNAME`**_ | string  |                        | Mixcloud username whose listening history should be monitored |
