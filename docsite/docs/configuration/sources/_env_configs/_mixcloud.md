| Environmental Variable   | Type    | Default                | Description                                                                                                                                                                                                     |
| ------------------------ | ------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _**`MIXCLOUD_ID`**_      | string  |                        | A globally unique ID EX `myComponentId`                                                                                                                                                                         |
| `MIXCLOUD_NAME`          | string  | Value of `MIXCLOUD_ID` | A vanity name EX `My Cool Component`                                                                                                                                                                            |
| `MIXCLOUD_ENABLE`        | boolean | true                   | Should this component be used?                                                                                                                                                                                  |
| `MIXCLOUD_USERNAME`      | string  |                        | Mixcloud username whose listening history should be monitored. Only required when clientId/clientSecret are not defined.                                                                                        |
| `MIXCLOUD_CLIENT_ID`     | string  |                        | Client ID of a Mixcloud application, from https://www.mixcloud.com/developers/. When defined (with clientSecret) the source authenticates with OAuth and can monitor private (pro account) listening histories. |
| `MIXCLOUD_CLIENT_SECRET` | string  |                        | Client secret of a Mixcloud application, from https://www.mixcloud.com/developers/.                                                                                                                             |
