| Environmental Variable   | Type    | Default                    | Description                             |
| ------------------------ | ------- | -------------------------- | --------------------------------------- |
| **`SOURCE_KOITO_ID`**    | string  |                            | A globally unique ID                    |
| `SOURCE_KOITO_NAME`      | string  | Value of `SOURCE_KOITO_ID` | A vanity name                           |
| `SOURCE_KOITO_ENABLE`    | boolean |                            |                                         |
| **`SOURCE_KOITO_URL`**   | string  |                            | URL for the Koito server                |
| **`SOURCE_KOITO_TOKEN`** | string  |                            | User token for the user to scrobble for |
| **`SOURCE_KOITO_USER`**  | string  |                            | Username of the user to scrobble for    |
