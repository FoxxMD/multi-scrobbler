| Environmental Variable      | Type    | Default                     | Description               |
| --------------------------- | ------- | --------------------------- | ------------------------- |
| **`SOURCE_MALOJA_ID`**      | string  |                             | A globally unique ID      |
| `SOURCE_MALOJA_NAME`        | string  | Value of `SOURCE_MALOJA_ID` | A vanity name             |
| `SOURCE_MALOJA_ENABLE`      | boolean |                             |                           |
| **`SOURCE_MALOJA_URL`**     | string  |                             | URL for maloja server     |
| **`SOURCE_MALOJA_API_KEY`** | string  |                             | API Key for Maloja server |
