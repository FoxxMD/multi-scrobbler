| Environmental Variable | Type      | Default          | Description                                                 |
| ---------------------- | --------- | ---------------- | ----------------------------------------------------------- |
| **`WS_ID`**            | string    |                  | A globally unique ID                                        |
| `WS_NAME`              | string    | Value of `WS_ID` | A vanity name                                               |
| `WS_ENABLE`            | boolean   |                  |                                                             |
| `WS_BLACKLIST`         | transform |                  | Block scrobbling from specific WebScrobbler Connectors      |
| `WS_WHITELIST`         | transform |                  | Only allow scrobbling from specific WebScrobbler Connectors |
