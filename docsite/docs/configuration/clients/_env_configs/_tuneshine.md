| Environmental Variable | Type    | Default            | Description                                       |
| ---------------------- | ------- | ------------------ | ------------------------------------------------- |
| _**`TUNE_ID`**_        | string  |                    | A globally unique ID EX `myComponentId`           |
| `TUNE_NAME`            | string  | Value of `TUNE_ID` | A vanity name EX `My Cool Component`              |
| `TUNE_ENABLE`          | boolean | true               | Should this component be used?                    |
| _**`TUNE_HOST`**_      | string  |                    | IP or http(s)://hostname for the Tuneshine device |
