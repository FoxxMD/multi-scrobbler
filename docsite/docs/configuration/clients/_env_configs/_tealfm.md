| Environmental Variable    | Type    | Default              | Description                                                                                              |
| ------------------------- | ------- | -------------------- | -------------------------------------------------------------------------------------------------------- |
| _**`TEALFM_ID`**_         | string  |                      | A globally unique ID EX `myComponentId`                                                                  |
| `TEALFM_NAME`             | string  | Value of `TEALFM_ID` | A vanity name EX `My Cool Component`                                                                     |
| `TEALFM_ENABLE`           | boolean | true                 | Should this component be used?                                                                           |
| _**`TEALFM_IDENTIFIER`**_ | string  |                      | The **fully-qualified** handle, or identifier, for your Atmosphere account                               |
| `TEALFM_APP_PW`           | string  |                      | The [App Password](https://atproto.com/specs/xrpc#app-passwords) you created for your Atmosphere account |
