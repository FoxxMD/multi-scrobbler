[**Mixcloud**](https://www.mixcloud.com/) is a platform for DJ mixes, radio shows, and podcasts.

This Source monitors the [listening history](https://www.mixcloud.com/developers/#listens) of a Mixcloud user and scrobbles newly discovered listens to configured clients.

<Aside type="info" title="Mixes, not Tracks">


Mixcloud's public API does not expose tracklists for mixes so each listen is scrobbled as a **single play for the entire mix**:

* **Track** is the name of the mix
* **Artists** are the hosts credited on the mix, or the account that uploaded the mix if there are no credited hosts
* **Duration** is the full length of the mix


</Aside>

## Setup

There are two ways to configure this Source:

* **Username** is easier and works for all **free** accounts.
* **Oauth** works for **all** accounts, including **Pro**. You will need to use this if your listening history is private.

<Tabs groupId="mixAccountType" queryString>
<TabItem value="username" label="Username (Recommended)">

Only your **username** is required to use this method. No authentication is required.

Your Mixcloud listening history must be **public** (the default), which you can verify by visiting `https://www.mixcloud.com/YourUsername/listens/` while logged out.

Your **username** is the last part of your profile URL IE `https://www.mixcloud.com/MyUsername/` => `MyUsername`

Use this with `MIXCLOUD_USERNAME` ENV or `username` File/AIO properties in configuration below.

</TabItem>
<TabItem value="oauth" label="OAuth">

If your listening history is private, or you have a pro account, authenticate with a Mixcloud application instead:

1. [Create an application](https://www.mixcloud.com/developers/) to get a **clientId** and **clientSecret**
2. Set these in your configuration below
3. Start multi-scrobbler and use the **Authorize** button/link for this Source to complete sign-in at Mixcloud

The user who completes the sign-in will be the monitored user for this Source.

The authorize flow redirects to `/api/mixcloud/callback` on the address the multi-scrobbler web UI is served from (default `http://localhost:9078`). If multi-scrobbler is behind a reverse proxy, complete sign-in from that address.

</TabItem>
</Tabs>
