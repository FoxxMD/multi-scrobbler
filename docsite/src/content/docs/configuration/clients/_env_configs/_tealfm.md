| Environmental Variable             | Type    | Default              | Description                                                                                                                                                                                          |
| ---------------------------------- | ------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _**`TEALFM_ID`**_                  | string  |                      | A globally unique ID EX `myComponentId`                                                                                                                                                              |
| `TEALFM_NAME`                      | string  | Value of `TEALFM_ID` | A vanity name EX `My Cool Component`                                                                                                                                                                 |
| `TEALFM_ENABLE`                    | boolean | true                 | Should this component be used?                                                                                                                                                                       |
| _**`TEALFM_IDENTIFIER`**_          | string  |                      | The **fully-qualified** handle, or identifier, for your Atmosphere account                                                                                                                           |
| _**`TEALFM_APP_PW`**_              | string  |                      | The [App Password](https://atproto.com/specs/xrpc#app-passwords) you created for your Atmosphere account                                                                                             |
| `TEALFM_RATE_LIMIT_RESERVE`        | number  | 1000                 | Points of the PDS rate limit to keep free. Scrobbling waits until the limit resets when fewer points are left.                                                                                       |
| `TEALFM_EXPORT_RATE_LIMIT_RESERVE` | number  | 1000                 | Points of the PDS rate limit to keep free when exporting from a Job. Exports wait until the limit resets when fewer points are left.                                                                 |
| `TEALFM_KEEP_ALL_HISTORY`          | boolean | false                | Keep every scrobble of your account in the multi-scrobbler database, instead of only the last 30 days. Older scrobbles are otherwise mirrored only when a dupe check needs them, then removed again. |
| `TEALFM_SCROBBLE_INTERVAL`         | number  |                      | Minimum time (milliseconds) to wait between scrobbles sent to this Client                                                                                                                            |
